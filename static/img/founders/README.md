# Photos des fondateurs

Déposez ici les portraits des fondateurs, nommés exactement :

- `founder-1.jpg`
- `founder-2.jpg`
- `founder-3.jpg`

Ils s'afficheront automatiquement sur la page **Le projet** (`/le-projet/`),
à la place des silhouettes. Format conseillé : portrait (ratio ~3:4),
largeur ~640 px, JPEG optimisé.

> Pour des profils complets (nom, rôle, biographie), créez plutôt des entrées
> *Fondateur·rice* dans l'administration (`/admin/`) — elles ont alors la priorité
> sur ces images.
